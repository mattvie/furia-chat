# furia-chat
Desafio técnico da FURIA

## Estrutura do Projeto

```
root/
│
├── client/          # Frontend em React
└── server/          # Backend em Node.js Express
```

O servidor se encontra [neste repositório](https://github.com/mattvie/furia-chat-server/).

Para utilizar a aplicação na web, acesse [aqui](https://furia-chat-tawny.vercel.app/).

## Executando Localmente

### Instalação de pacotes

```
npm install
```

### Executando em modo de desenvolvimento

```
npm start
```
